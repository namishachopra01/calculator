# Calculator

An aesthetic and responsive **web-based calculator** created using HTML, CSS, and JavaScript. The calculator performs common arithmetic operations through an easy-to-use interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear (AC) functionality
- Delete/backspace functionality
- Division-by-zero handling
- Keyboard support
- Responsive design for different screen sizes
- Clean and modern user interface

## Technologies Used

- **HTML5** — Creates the calculator structure and buttons
- **CSS3** — Provides the layout, colors, styling, responsiveness, and visual design
- **JavaScript** — Handles calculator operations, button events, calculations, and keyboard input

## What I Learned

This project helped me understand JavaScript event listeners, DOM manipulation, functions, conditional statements, arithmetic operations, user input handling, and how JavaScript can be used to add functionality to an HTML and CSS interface.
